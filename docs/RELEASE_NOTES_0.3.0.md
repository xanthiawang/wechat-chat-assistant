# v0.3.0 Beta

- 独立用户级早报调度：提前准备、08:00核对同步、09:00投递，中午前可在唤醒后补发。准备失败有上限重试，成功批次按账号、模型设置和原文缓存。发送结果不明时停止盲目重发。
- 普通用户待办导入：粘贴或选择TXT、Markdown、CSV、JSON，预览修改联系人、项目、责任、日期与完成状态后确认保存。原始来源及确认记录保留本机。重复导入保留原任务状态；同名独立事项可显式单独保存。
- 旧程序更新先检查运行锁并备份，保留授权、任务及投递回执。已有真实试发回执时可只修复调度，不重复试发。

电脑休眠、合盖、断电或离线时无法承诺09:00送达；本机调度不能唤醒已关闭的电脑。应用未经过Apple公证，第二台全新Mac的完整登录与读取初始化仍需验收。
