# v0.2.0 Beta

## 新增

- 原生 Mac 配置应用：四步引导、恢复入口、实际运行与最近简报状态。DMG 安装和应用 ZIP 均只包含允许公开的程序文件。
- 本机语气样本、修改候选、关系候选与独立学习；持久待办、主人完成反馈与后续提醒移除。
- 四章简报与项目主题分组，三级编号、联系人与下一步、日程状态、备用待办、逐页真实回执与不确定状态保护。
- 准备与投递分离；08:20 准备、09:00 投递。读取子进程有期限，学习避让晨报。
- 已有安装可继续配置；诊断区分保存的配置、最近记录和实时调度状态。
- 从 Finder 启动时补齐 Homebrew 路径；首次安装明确启动独立后台服务。

## 仍有限制

- Apple Silicon / macOS 14+，未经过 Apple 公证，未在第二台全新 Mac 做端到端验收。
- 仍使用可审阅的终端向导进行本人授权。不是静默或零操作安装。
- 不支持其他联系人代发、图片或语音解析、Windows 与 Intel Mac。
- 已有旧安装不自动覆盖代码；保留程序和私人状态后按恢复文档迁移。
- 休眠、离线、服务重启、订阅额度或微信会话有效性会影响 09:00 投递；自动准点投递尚不能视为稳定验收。

配置体验参考了 [CodeIsland 的下载应用与引导安装方式](https://github.com/wxtsky/CodeIsland)。本项目独立编写配置界面，不包含其代码。
