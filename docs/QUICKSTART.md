# 四步配置

## 准备

Apple Silicon Mac、macOS 14+、Mac 微信 4.x 和本人的 ChatGPT/Codex 订阅。需要可访问 GitHub、npm、模型服务和微信的网络。

先从 [Homebrew 官网](https://brew.sh) 安装 Homebrew。如系统未安装 Command Line Tools，按提示运行 `xcode-select --install` 并等待完成。安装器不会偷偷安装系统依赖，也不会替你输入密码。

## 1. 安装与环境

从本项目 v0.3.0 发布页下载 DMG，将应用拖到 Applications 后打开。应用未公证，按 macOS 的安全确认流程处理首次打开；不要关闭 Gatekeeper 或 SIP。

点击“开始／继续”，Terminal 会打开同一份可审阅的安装向导，安装固定版本依赖和独立后台服务。不要同时点击其他配置步骤。

## 2. 模型与微信

在终端完成订阅登录；没有自动打开网页时，使用终端提供的官方地址及本次设备代码。微信扫码后，用手机本人确认，再在机器人会话发送“你好”。

相关聊天会交给该模型服务处理并消耗订阅额度。没有另收代码费用，不自动购买 API。

## 3. 聊天读取

先保存草稿、完成微信官方备份，再正常退出微信。同意向导说明的临时副本初始化；可能需要手机确认。结束后打开原版微信，确认能正常查看聊天。

官方备份完成不等于自动读取成功。只读验证不通过就停在此步骤，不显示“已接入”。

## 4. 验证与早报

“验证并启用”会执行真实模型检索、发送完整昨日简报；这会使用订阅额度并向你自己的微信发送测试内容。两项均通过后才创建／启用调度。

独立本机调度从北京时间00:15后提前准备，08:00核对新增同步，09:00投递；重启后台不会同时终止独立准备进程。失败按上限重试，唤醒后最迟中午补发。请保持电脑开机联网；应用不自动唤醒合盖的电脑。

## 导入自己的待办

完成读取验证后，点击应用里的“导入待办”。粘贴每行一条的清单，或选择TXT、Markdown、CSV、JSON文件；在预览页填写联系人、项目／主题、责任和日期，勾选需要保存的事项后点击“我已核对，保存选中事项”。无需编辑配置文件，导入不调用模型。

CSV可使用“事项、联系人、项目、责任、日期、说明”列；JSON接受任务数组或包含tasks的对象。每次最多200项、1MB。Markdown里的完成勾选不会自动划掉任务，须本人在预览中选择“已完成”。重复导入不会新增或重开原任务；同名但不同的事项可选“单独保存”。

保存后可在微信说“某件事完成了”，重名时补充联系人或项目。状态更新后不再作为未完成事项提醒；说“恢复某件事提醒”可恢复。原始文件和核对结果留在本机。

## 中断后

回到应用，点击“刷新状态”，再继续对应步骤。状态里“已保存绑定／读取验证”是已有配置标记，实时调度另行检查；失败不代表没有聊天。

已有兼容版本在“开始／继续”中可确认更新代码；先备份旧程序，保留授权、记忆、任务和发送回执，失败回滚。若需迁移依赖则停止并说明。请查看 [恢复说明](RECOVERY.md)。其他联系人代发、语音／图片理解不在此公开版中。
