# 四步配置

## 准备

Apple Silicon Mac、macOS 14+、Mac 微信 4.x 和本人的 ChatGPT/Codex 订阅。需要可访问 GitHub、npm、模型服务和微信的网络。

先从 [Homebrew 官网](https://brew.sh) 安装 Homebrew。如系统未安装 Command Line Tools，按提示运行 `xcode-select --install` 并等待完成。安装器不会偷偷安装系统依赖，也不会替你输入密码。

## 1. 安装与环境

从本项目 v0.2.0 发布页下载 DMG，将应用拖到 Applications 后打开。应用未公证，按 macOS 的安全确认流程处理首次打开；不要关闭 Gatekeeper 或 SIP。

点击“开始／继续”，Terminal 会打开同一份可审阅的安装向导，安装固定版本依赖和独立后台服务。不要同时点击其他配置步骤。

## 2. 模型与微信

在终端完成订阅登录；没有自动打开网页时，使用终端提供的官方地址及本次设备代码。微信扫码后，用手机本人确认，再在机器人会话发送“你好”。

相关聊天会交给该模型服务处理并消耗订阅额度。没有另收代码费用，不自动购买 API。

## 3. 聊天读取

先保存草稿、完成微信官方备份，再正常退出微信。同意向导说明的临时副本初始化；可能需要手机确认。结束后打开原版微信，确认能正常查看聊天。

官方备份完成不等于自动读取成功。只读验证不通过就停在此步骤，不显示“已接入”。

## 4. 验证与早报

“验证并启用”会执行真实模型检索、发送完整昨日简报；这会使用订阅额度并向你自己的微信发送测试内容。两项均通过后才创建／启用调度。

北京时间 08:20 准备、09:00 投递。请保持电脑开机联网，早晨不要合盖休眠或重启后台；应用不会自动唤醒合盖的电脑。

对于已经导入的待办，可直接说“某件事完成了”。准确定位并更新本机任务状态后，后续提醒不再列它；说“恢复某件事提醒”可恢复。当前没有普通用户待办导入界面，也不会自动把全部聊天里的事项保存成跨日任务。

## 中断后

回到应用，点击“刷新状态”，再继续对应步骤。状态里“已保存绑定／读取验证”是已有配置标记，实时调度另行检查；失败不代表没有聊天。

已有不同版本的安装只会恢复原有配置，不会把新版本代码强行覆盖到旧程序。请查看 [恢复说明](RECOVERY.md)。其他联系人代发、语音／图片理解不在此公开版中。
