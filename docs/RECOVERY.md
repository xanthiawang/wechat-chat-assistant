# 安装与恢复

## 前置准备

- Apple Silicon Mac，原生终端，Mac微信4.x已登录并同步。
- Homebrew、Apple Command Line Tools、可访问npm/GitHub/模型服务的网络。
- 自己的ChatGPT/Codex订阅；自己可进行微信扫码及手机登录确认。
- 初始化前保存微信草稿，完成官方备份。从微信菜单正常退出，不强制终止原版。

## 向导中断

已有配置不覆盖。安装后可用 `setup.py connect` 重做本人授权，`reader`
初始化读取，`verify` 检查真实数据库，`enable` 验证并开启简报。
`connect`、`reader`和`verify`会先暂停已有简报及模型历史查询，避免旧验证状态
用于新账号或失效密钥；确认通过后重新执行`enable`。纯状态查看请使用`doctor`。

如果安装在创建配置之前中断，安装器会拒绝覆盖残留的 `app`／`runtime`。
先查看这些目录，保留已生成数据，再把此次**未完成安装目录**改名为带日期的
备份目录，重新安装。不要删除或改名你已有的其他OpenClaw profile。

## 读取失败

- 临时副本失败不代表聊天为空。原版签名应保持原状。
- 向导恢复原版后，必须本人确认能登录并正常打开聊天。
- 如果尚有临时窗口，先正常退出该窗口，打开 `/Applications/WeChat.app`。
- 如果密钥不完整、版本升级后密钥失效或出现新数据库，重新执行 `reader`
  和 `verify`。保持官方备份，不清除账号数据，不降低macOS安全保护。
- 多账号选择时只选本人当前登录账户；无法确认则停止。

## 模型／微信通道失败

执行 `connect` 重新授权。没有订阅额度或网络不可用时不会自动切换收费API。
在微信助手会话发一条“你好”建立有效上下文；发送接口仍可能拒绝主动消息，
因此以真实试发为准。代理URL仅保存在本机，不写进仓库。

## 简报发送不确定

`reports/<账号绑定哈希>/<日期>/status.json` 若为 `delivery_pending` 或 `delivery_unknown`，
不要盲目重发。先查看本人微信是否收到，再由本人决定是否重试。
已确认发送的日期有去重标记。模型失败或数据缺失时不发送成功简报。
账号绑定包含机器人账号、认证主人、本地微信ID和数据目录。更换账号不能复用
旧账号的已发送回执；处理中的简报完成前，向导不会改变绑定配置。

## 更新与卸载

Beta不做自动覆盖升级。程序、个人数据和profile分离；更新前保留配置和
数据，并按新版本迁移说明操作。安装器遇到既有安装会转为恢复提示。

`setup.py uninstall` 仅停用此profile的简报和后台服务，保留聊天、读取密钥
和登录状态。若要删除这些个人数据，请本人逐项审查；本项目不执行清空操作。
