# 微信聊天助手

在微信里问聊天里的事，每天 09:00 收一份有联系人、有下一步的简报。

## 下载后怎么用

1. 下载 `WeChat-Chat-Assistant-0.2.0-arm64.dmg`，把“微信聊天助手”拖入 Applications。
2. 打开应用，点“开始／继续”，按向导安装依赖。
3. 连接本人的 ChatGPT/Codex 订阅，微信扫码，给机器人发“你好”。
4. 完成微信官方备份并单独同意读取初始化；真实检索与完整简报试发通过后，开启每日 09:00 投递。

应用展示配置步骤、实时调度检查、最近简报和学习状态。授权、扫码和读取确认会在终端中由你完成；不需要手写配置文件，但仍需要本人操作。

> **当前是 Beta，不是零操作安装。** 仅支持 Apple Silicon、macOS 14+、Mac 微信 4.x，需要 Homebrew 与 Apple Command Line Tools。应用是临时签名构建，未经过 Apple 公证，首次打开可能被系统阻止；请按系统提供的安全确认流程操作，不关闭系统保护。尚未在另一台全新 Mac 完成端到端验收。

也可下载源码 ZIP，解压后双击 `Install.command`；或者启动固定版本的终端向导：

```bash
curl -fL https://github.com/xanthiawang/wechat-chat-assistant/releases/download/v0.2.0/install.sh -o /tmp/wechat-assistant-install-v0.2.0.sh && bash /tmp/wechat-assistant-install-v0.2.0.sh
```

引导脚本下载固定版本并核对内置 SHA256；发布页另附所有资源的 `SHA256SUMS`。

## 能做什么

| 功能 | 当前范围 |
|---|---|
| 微信问答 | 在本人 ClawBot 会话中检索此 Mac 已同步的文字 |
| 每日简报 | 北京时间 08:20 准备，09:00 尝试投递前一天简报 |
| 待办 | 对已导入的有来源任务维护状态；本人确认完成后，从后续提醒中移除 |
| 说话语气 | 检索同一联系人的真实本人表达，参考已关联的修改候选起草 |
| 关系记忆 | 带原始消息来源的关系与项目候选，回复前仍需核对 |
| Mac 配置应用 | 引导、恢复入口与状态检查；不另开常驻 AI 或录屏服务 |
| 向其他联系人代发 | **不包含在此公开 Beta**；原型尚未完成真实发送验收 |
| 图片、语音、附件 | 尚不解析，不能声称理解内容 |
| Windows / Intel Mac | 尚不支持 |

“本机已同步”不等于手机全部历史。微信官方备份也不直接作为可读输入。

## 简报与完成反馈

简报固定为四章：需要处理、日程安排、项目进展、其他关注。

- 三级编号：`一、 → （一） → 1.`。
- 小类按项目／主题分，不按人名增加层级。
- 条目如“合同负责人｜合同：确认版本与签署时间”；明确对接人、执行者及下一步，不添加“找”字引导。
- 日程区分“已确认／待确定”。来源、内部编号和技术注释留本机，按需查详情。
- 已完成、已取消的任务不再列为待办。完成状态只接受主人当前的明确反馈，不根据会议原话或模型猜测划掉。

在微信中说“查看待办”“某件事完成了”或“恢复某件事提醒”。也支持 `/todo done 完整事项名称`、`/todo reopen 完整事项名称`。模糊或同名事项先确认，不误改其他任务。

当前持久待办需要先通过本机接口导入有来源的事项；尚未提供面向普通用户的导入界面或从所有聊天自动入库。每日简报仍可从当日聊天总结待处理事项，但不等于已经保存成跨日任务。

**电脑需开机、联网且服务可用。休眠、合盖、订阅额度不足、网关重启或微信会话失效都会影响准点发送。** 开启定时不代表成功送达，应用会显示最近一次真实运行状态；失败时可发送备用待办，发送结果不明时停止盲目重试。

## 记忆如何工作

使用本机 SQLite，无常驻图数据库、向量库或本地大模型。首次索引最近 14 天文字，之后增量处理，每轮最多 3000 条。

独立学习每天 05:30、11:30、17:30、23:30 运行，08:00–10:00 避让晨报。单轮最多 4 分钟，最多读取最近 24 小时的 80 条文字、保存 12 个关系候选和 120 条语气样本。

修改学习需要关联真实草稿和后来实际发出的修改消息。本人发出不证明原创，观察到的修改也不是模型训练或准确率证明；当前尚未完成首次真实人工修改回流验收。

## 隐私与费用

- 程序、密钥、记忆、任务和回执在 `~/.local/share/wechat-chat-assistant/`，独立 profile 为 `wechat-chat-assistant`。
- 只读微信源数据库，仅给主人提供问答与推送，不自动回复其他联系人或群聊。
- **不是完全本地 AI**：总结与问答会把相关文字发送给本人授权的 OpenAI 服务，使用订阅额度；不自动配置收费 API 备用通道。
- 初始化需要本人同意后运行临时重签名微信副本来获取数据库读取密钥，存在兼容性与账号检测风险。原版微信签名及 SIP 不改变。
- 私人配置、聊天、密钥、草稿、画像及回执不进入 GitHub 或发布包。正常卸载保留这些数据。

## 开发与发布

```bash
python3 scripts/check_package.py
# macOS + Command Line Tools；产生源码包、配置应用 ZIP、DMG 和校验和
python3 scripts/build_release.py --macos
```

发布只使用 `scripts/public_files.json` 明确列出的通用源码。源码归档规范化时间与权限；编译后的应用不宣称可重复构建。原生配置界面仅负责启动既有向导和读取状态，不复制 CodeIsland 的程序代码。

源码 `main` 与下载包版本需分别核对；[v0.2.0 变化与限制](docs/RELEASE_NOTES_0.2.0.md)。已有旧安装不会自动覆盖升级，先按恢复文档保留原程序及个人状态。
